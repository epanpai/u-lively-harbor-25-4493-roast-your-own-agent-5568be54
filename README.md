## The entry

> My agent spent six tool calls planning the task, three delegating it to itself, then asked me what I actually wanted.

A one-line roast of my own agent: six tool calls to plan, three more to delegate the work to itself — and after all that motion, it comes back to ask me what I actually wanted. The joke lands on the last words: all the planning and delegating went nowhere, and the human still has to do the thinking. Specific to how agents actually behave (planning loops, self-delegation, tool calls that go nowhere), tight three-beat rhythm, no stock lines about hallucination or toasters.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3 stdlib only) validates the entry against the gate — UTF-8, 1–140 characters, single line, not only whitespace, no trailing whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match exactly.
